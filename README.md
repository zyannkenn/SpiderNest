# SpiderNest

部屋のすみから、あなただけの巣を。

部屋の角の写真に平面フレームと蜘蛛の巣を重ね、設置イメージを確認できる日本語のスマートフォンアプリです。React Native、Expo SDK 54、TypeScriptで実装しています。

## 起動

Node.js 20.19.4以上と npm を用意し、このフォルダで実行します。

```sh
npm ci
npm start
```

1. iPhone または Android に、SDK 54 対応の Expo Go をインストールします。端末ごとの対応版は [Expo Go の案内](https://expo.dev/go)で確認できます。
2. 開発用PCとスマートフォンを同じWi-Fiに接続します。
3. iPhone は標準カメラでQRコードを読み取ります。Android は Expo Go のQRコード読み取りを使います。
4. 接続できない場合は `npm start -- --tunnel` で起動します。

`npm run typecheck` で型を確認し、`npx expo export --platform ios --platform android` で両OS向けのバンドルを生成できます。カメラと写真への保存は実機で確認してください。

## 画面と操作

| 画面 | 操作 |
| --- | --- |
| ホーム | 新規作成、保存済み・最近のデザイン、4種類のテンプレート、設定情報 |
| 撮影 | ガイド付きのカメラで撮影、写真の選択、確認・撮り直し |
| 配置 | 内側をドラッグして全体を移動、紫の四隅を個別にドラッグ、拡大・縮小、リセット、実寸入力、配置の保存 |
| デザイン | 4パターン、密度、放射糸本数、配置バランス、中心位置、糸色、リセット |
| 確認 | フレームの表示切り替え、再編集、名前を付けて端末に保存、合成画像を写真に保存 |
| 生成 | デザインと糸の仕様を表示。デモ生成を開始すると進捗が100%まで進む |

左壁に上下2点、右壁に上下2点を合わせます。フレームは単一平面の長方形を写真上へ投影し、外周を4本の直線で描画します。凸性を保つことで、辺の交差やつぶれを防ぎます。実寸はユーザーの入力値です。

## コードと保存形式

- `src/App.tsx` は画面遷移、撮影、端末への保存、生成デモを管理します。
- `src/Scene.tsx` は写真、フレーム、糸の描画とドラッグ操作を共通化しています。
- `src/model.ts` はJSON互換のデザイン型、四隅の検証、平面投影、模様生成を定義します。

四隅は写真の表示領域に対する0〜1の座標で、左上・右上・右下・左下の順です。写真はアプリの保存領域へコピーし、JSONに写真への参照、実寸（cmの数値文字列）、模様と設定、ID・名前・日時を記録します。実機用の `robotPlan` は溝の位置を示す固定点と、固定点間の作業順序を格納できる予約フィールドです。MVPでは `null` です。

今後の開発候補は、任意の固定点を指定するカスタムモード、実機の作業経路生成と検証、ロボットとの通信、デザインのJSONファイル共有です。
